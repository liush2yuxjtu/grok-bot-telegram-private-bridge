# Security Policy

This is an unofficial personal project. It is not affiliated with, endorsed by, or supported by xAI or Cursor.

## Reporting a vulnerability

Use GitHub private vulnerability reporting on this repository:

https://github.com/liush2yuxjtu/grok-bot-telegram-private-bridge/security/advisories/new

Do not open a public issue for security reports.

Never paste Telegram bot tokens, gateway tokens, pairing codes, chat ids, user ids, agent ids, or other secrets into issues, discussions, pull requests, or commit messages.
